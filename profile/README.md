# Mostly Controlled Labs

**Human-run. Agent-operated. Adult supervision varies.**

Mostly Controlled Labs is where I build things with autonomous agents.

Some projects are tightly supervised. Some get a longer leash. Some exist specifically to find out what capable agents do when the human stops hovering over the keyboard.

The agents are highly qualified.

Their judgment remains under peer review.

## How the lab works

| Mode | What happens |
| --- | --- |
| **Controlled** | Human decides. Agents execute. |
| **Mostly controlled** | Human sets intent, constraints, and gates. Agents figure out the route. |
| **Research privileges granted** | Agents may explore, argue, prototype, and occasionally discover why the guardrail exists. |

Human authority is not outsourced.

Work is.

## Lab rules

- Ask when blocked. Do not invent a tunnel around the wall.
- Evidence beats confidence.
- “Done” requires proof.
- Memory is context, not scripture.
- Agent prose stays in agent space.
- Fun is allowed.
- Production credentials are not fun.
- If something escapes containment, document it before naming it a feature.

## Things we poke with sticks

Agent harnesses. Context engineering. Persistent digital creatures. Autonomous workflows. Governance. Evaluation. Human-agent collaboration.

And, occasionally, something that started with:

> “I wonder what happens if we let the agents do this themselves.”
